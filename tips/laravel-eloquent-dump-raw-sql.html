Inline Query Inspection with dumpRawSql() and ddRawSql()

Punyapal Shah • Aug 4, 2026
Chain dumpRawSql() or ddRawSql() directly onto an Eloquent query builder to print executable SQL statements without interrupting method chains.

Stopping execution to log or print query SQL often requires breaking method chains. Using dumpRawSql() lets you inspect queries mid-chain while continuing builder execution, while ddRawSql() dumps and halts immediately.

use App\Models\User;

$users = User::where('active', true)->dumpRawSql()->where('role', 'admin')->get();
User::where('email', 'like', '%@company.com')->ddRawSql();
  • Inspect SQL statements mid-chain without breaking query builder flows
  • Outputs fully interpolated SQL strings ready for database consoles
  • Use dumpRawSql() to log mid-stream or ddRawSql() to halt execution
